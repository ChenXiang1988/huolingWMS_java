# 本次界面与交互差异

## 1 本次交互

| 端 | 作业 | 动线与编号 | 分支与出口 |
|---|---|---|---|
| 货主端 | 新建与编辑档案 | 列表页点新建或编辑 → 操作抽屉（`UI-C31`）填分组表单（`UI-C03`）→ 保存或提交 → 受理号（`UI-I12`、`UI-F01`）→ 按 `API-015` 每 3 秒轮询处理中（`UI-F02`）→ 结果到达（`UI-F03`） | 必填缺失就地提示；版本冲突提示刷新；离开未保存表单按 `UI-I07` 提示；写入按 `UI-I05` 禁用提交按钮 |
| 货主端 | 提交审核与删除 | 草稿或驳回态提交；启用态点删除 → 按 `UI-F05` 二次确认 → 受理号 → 按 `API-015` 轮询 → 结果 | 状态不满足时按钮置灰并给原因（`UI-I03`）；删除只做逻辑停用，文案用「停用」（`UI-W01`）；失败出口为重试或返回列表（`UI-I06`） |
| 运营端 | 全量查询与代建 | 列表页筛选（`UI-C02`）→ 表格（`UI-C01`）→ 行点击侧拉详情抽屉（`UI-D01`、`UI-D04`）→ 详情内查看分区；代建在详情关闭后开操作抽屉（`UI-D09`）并指定归属货主 | 归属未指定禁止提交；详情内异常按 `UI-D11` 就地处理；列表上下文按 `UI-D08` 保留 |
| 运营端 | 单条与批量审核 | 审核列表勾选 → 通过或驳回；驳回必填原因 → 受理号 → 按 `API-016` 轮询 → 逐条结果 | 批量前回显影响条数（`UI-X02`）；部分成功按 `UI-I08` 列成功失败条数与原因；跨页选择按 `UI-X01` |
| 单仓端 | 本仓查询 | 进入列表 → 筛选 → 表格 → 详情抽屉；降级数据顶部提示条显示数据时间（`UI-S05`、`UI-S07`） | 版本落后显示待刷新，刷新取实时；跨仓数据按 `UI-S03` 无权限处理 |
| 单仓端 | 发起变更申请 | 详情抽屉内点发起变更 → 关闭详情后开操作抽屉（`UI-D09`）→ 选字段、填目标值与原因 → 提交 → 受理号 → 按 `API-017` 轮询 → 结果 | 不允许直接改主数据字段；同一档案已有待审申请时按 `API-014` 前置判定并置灰给原因；状态跟踪页查询进度（`UI-F02`、`UI-F03`） |
| 单仓端 | 会话获取与续期 | 应用级会话门按 `UI-P03` + `UI-C03` 采集站点编码与凭证 → 调用 `API-018` 获取站点令牌、仓标识与权限 → 令牌即将过期调用 `API-019` 续期 | 会话门不占独立路由；多仓声明或凭证错误按 `UI-S03` 无权限处理；续期失败保留当前页并给重新登录出口 |
| 运营端 | 代建归属选择 | 打开代建表单 → 调用 `API-020` 搜索并选择归属货主 → 未选时提交置灰 | 搜索无结果给 `UI-S02` 空态；失败按 `UI-S04` 给重试 |

所有写入交互先到受理号，再按所属端通过 `API-015`、`API-016`、`API-017` 轮询到结果，不在前端判断业务结果（`UI-I11`）；动作词统一按 `UI-W01`，商品档案状态词统一为草稿、待审核、启用、驳回、停用。

## 2 本次界面

| 端 | 页面 | 骨架与组件 | 规格要点 |
|---|---|---|---|
| 货主端 | 商品档案列表与表单 | `UI-P01`、`UI-C01`、`UI-C02`、`UI-C08`、`UI-C31` | 只见自有档案，不出现库位号与部署位置（`UI-P05`）；筛选与分页参数留在地址栏 |
| 货主端 | 商品档案详情 | `UI-D01`、`UI-D02`、`UI-D03`、`UI-D04`、`UI-D05`、`UI-D07` | 分区顺序为基础信息、计量包装、保管扩展、追溯控制、审核记录；详情导航常驻 |
| 运营端 | 全量档案列表、审核列表、变更申请列表 | `UI-P01`、`UI-C01`、`UI-C02`、`UI-C06`、`UI-C07`、`UI-C08` | 状态标签常驻同一列；主操作右对齐；紧凑行高按既有高密度档 |
| 运营端 | 代建、审核、驳回操作 | `UI-C31`、`UI-C05`、`UI-F05`、`UI-X02` | 驳回原因在弹窗内必填；危险操作二次确认；提交中关闭置灰 |
| 单仓端 | 本仓档案列表与详情 | `UI-P01`、`UI-C01`、`UI-C02`、`UI-D01`、`UI-D04` | 触摸优先；降级提示条常驻到刷新成功（`UI-S07`） |
| 单仓端 | 变更申请表单与跟踪页 | `UI-P03`、`UI-C03`、`UI-C31`、`UI-C08` | 字段集合限定为 `name`、`spec`、`category`、`storageCondition`；不出现库位关联字段 |
| 单仓端 | 应用级会话门 | `UI-P03`、`UI-C03`、`UI-S03`、`UI-S06` | 采集站点编码与凭证，不占路由；多仓或凭证错误就地提示 |

受理查询降级时按 `UI-S05`、`UI-S07` 显示数据时间与重试出口，不用空结果掩盖故障。状态表达覆盖 `UI-S01` 加载、`UI-S02` 空数据、`UI-S03` 无权限、`UI-S04` 接口失败、`UI-S05` 降级数据，错误码按 `UI-S06` 展示。
