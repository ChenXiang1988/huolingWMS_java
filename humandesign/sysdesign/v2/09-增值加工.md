# 增值加工

## 1 结论

首期只做四种轻加工动作（D44 归为三类：贴标、换包装、组合拆包），组合与拆包用单层组成关系表达；加工单是作业单，在制落在真实工位库位；投入与产出按组成关系展开校验，差异只能冲正，不能挂账。

## 2 问题与范围

**解决**：定住加工的边界、加工单的结构、在制怎么表达、损耗怎么处理、与入出库主流程的衔接、计费事实、首期明确不做的范围。

**不解决**：多级物料清单与配方（不做）、工序级领料与报工（属 MES）、工时定额的测算方法（属策略参数）、库位模型细节（见 04）。

## 3 设计

### 四种动作、三类，组成关系不超过一层

依据 D44（把组合与拆包合为一类）。

| 类型 | 投入 | 产出 | 组成关系 |
|---|---|---|---|
| 贴标 | 同 SKU | 同 SKU，只加标签 | 无 |
| 换包装 | 同 SKU | 同 SKU，包装规格变 | 无 |
| 组合 | N 个子件 SKU | 一个套装 SKU | 单层 |
| 拆包 | 一个套装 SKU | N 个子件 SKU | 单层 |

**单层组成关系**只有两个字段：套装 SKU、子件 SKU 与用量。不做多层嵌套（套装里套套装）、不做比例配方（如"每 100 kg 加 3 kg"）。

判定标准：如果一次加工需要展开两层以上的组成关系，说明超出首期范围，应拆成多张加工单先后执行。

### 加工单是作业单，行上必须带库位

依据 D56 的两族划分：加工离开库位无法表达，所以归作业单。

| 部分 | 装什么 |
|---|---|
| 单头 | 加工类型、货主、仓库、计划开始与结束、来源单据号 |
| 投入行 | SKU、批次、**库位**、数量 |
| 产出行 | SKU、批次、**目标库位**、数量 |
| 损耗行 | 数量、去向（报废 / 返工 / 差异） |

单头不装 SKU 与数量，全部在行上；一个加工单可以多投入多产出，靠组成关系约束平衡。

状态与其他单据一致，走五态（已受理 / 执行中 / 已完成 / 差异关闭 / 已取消），不另造状态机。

### 在制落在真实工位库位，走两次库存变动

依据 INV-16 与 D26（禁止虚拟库位）。

```
投入：存储位 ──转移──> 工位库位（WIP）
产出：工位库位（WIP）──转移──> 存储位
```

| 规则 | 内容 |
|---|---|
| 工位库位 | `loc_type = WIP`，有真实四段坐标，参与盘点与容量核算；工位不建独立对象（见 04） |
| 库存变动次数 | 两次转移，不是一次「属性变化」 |
| 在制期间 | 库存挂在 WIP 库位，货主与批次不变 |
| 禁止 | 「在制池」「虚拟车间仓」一类的逻辑容器 |

两次转移的好处是：在制库存随时可见（就在某个工位上），出问题时能定位到具体位置，而不是消失在一个池子里。

### 平衡按组成关系展开校验，不是简单数量相等

INV-17 要求"投入减产出减损耗约等于零"，但组合与拆包的数量单位不同，不能直接相加。所以按类型分三种平衡规则：

| 类型 | 平衡规则 |
|---|---|
| 贴标、换包装 | 投入数量 = 产出数量 + 损耗数量（同 SKU、同单位） |
| 组合 | 产出套装数 × 每个子件的用量 = 各子件的投入数量（逐子件校验） |
| 拆包 | 投入套装数 × 每个子件的用量 = 各子件的产出数量（逐子件校验） |

举例：套装 C = 2×A + 1×B。投入 10 个 A、5 个 B，正产出 5 个 C。

```
A：5 套 × 2 = 10，投入 10，平衡
B：5 套 × 1 = 5，投入 5，平衡
```

若只投入 9 个 A，则差 1 个 A，加工单不能完成，必须走差异关闭或补料。

组合与拆包不校验"总数相等"，只校验**逐子件展开后相等**。这条比简单的数量相减可靠。

### 损耗必须有去向，三种去向三种后续

| 去向 | 含义 | 后续动作 |
|---|---|---|
| 报废 | 不可用 | 转移到报废库位（`loc_type=SCRAP`），产生报废记录 |
| 返工 | 可再加工 | 留在 WIP，等下一张加工单 |
| 差异 | 账实不符 | 走差异流程，生成库存异常记录，由调整单入账 |

不允许"损耗挂账"——损耗数量必须当场指定去向，否则加工单不能完成。这是 INV-17 的落点。

### 加工单挂在主流程的入库侧或出库侧

依据 D57：加工是插入主流程的一环，不产生第二条链路。

| 位置 | 插入点 | 典型场景 |
|---|---|---|
| 入库侧 | 收货完成之后、上架之前 | 到货贴中文标、换零售包装 |
| 出库侧 | 拣货完成之后、复核之前 | 出库贴渠道标、组合成礼盒 |

四条规则：

1. **两侧都开时各生成一张加工单**，各记各的在制与计费，不合并。
2. **入库贴标与出库贴标是两个独立开关**，可以只开一个（见 D57）。
3. **加工单不改变主流程单据的状态机**：主流程单据停在「执行中」，加工完成后继续下一个任务。
4. **贴什么标不进作业要求项**：要求项只回答"这一步要不要贴"，标签模板、语言、条码规格由加工单的行指定。WMS 不判断标签语义，也不自行去重。

### 加工能力由作业要求项触发，不靠人工临时判断

依据 D57 的四级继承：

```
单据行显式指定  >  货品作业要求  >  货主默认  >  仓库默认
```

一处配置决定三件事，三者同源：**是否生成加工单、作业端是否出现任务、是否产生计费事实**。

所以不允许"操作员看着办，需要贴就手工建一张加工单"——手工建单只在要求项漏配时作为补救，且必须记录原因。

### 加工完成产生一条计费事实

| 字段 | 内容 |
|---|---|
| 事实类型 | 加工完成 |
| 服务项 | 贴标 / 换包装 / 组合 / 拆包（按类型分别定价） |
| 数量 | **按投入数量计**，不按产出 |
| 时间 | 加工完成时间 |

按投入数量计的理由：加工费对应的是干活量，投入多少件就要处理多少件；按产出计会在组合场景下失真（投入 10 件出 5 个套装，按产出算只收 5 件的钱）。

损耗不影响计费基数——损耗的件也干过活。

### 加工不跨仓、不跨货主

一单一货主一仓（D56）。跨仓加工等于跨仓移库加加工，拆成两张单，不在加工单里表达。

## 首期明确不做

| 不做 | 归属 | 说明 |
|---|---|---|
| 多级物料清单 | MES / PLM | 需要 BOM 展开与工艺路线，不是轻加工 |
| 配方与比例投料 | 流程制造 MES | 需要称重、浓度、批次追溯 |
| 工序级领料与报工 | MES | 需要工单、工序、工时、良率 |
| 加工工时定额 | 工艺工程 | 首期用固定值，不做动作时间研究 |
| 加工中的质检环节 | 质量管理 | 质检在收货环节（QC 库位），不在加工里 |
| 加工设备与工装管理 | 设备管理 | 加工是人工或简单工具完成 |

## 4 约束与验证

| 约束 | 强制手段 |
|---|---|
| 在制必须在 WIP 库位 | 数据库层：加工单行的库位外键非空，且库位类型必须为 WIP；核对层：日结扫描"加工中但库位非 WIP"的记录 |
| 两次库存变动 | 应用层：投入与产出各发一次库存事件，不允许一次事件改属性；核对层：库存流水里加工单必须有成对的转出与转入 |
| 平衡逐子件校验 | 应用层：组合与拆包按组成关系展开比对，不平则拒绝完成；核对层：日结核对加工单的投入与产出与组成用量 |
| 损耗必须指定去向 | 数据库层：损耗行去向非空；应用层：未指定去向不允许完成 |
| 不挂账 | 核对层：日结扫描"执行中超过阈值未完成"的加工单，超期告警 |
| 组成关系只有一层 | 数据库层：套装 SKU 不得作为子件出现在另一条组成关系里（约束校验） |
| 加工单不改主流程状态 | 代码层：加工模块不引用单据状态变更接口 |
| 计费事实按投入量 | 集成层：事实报文只带投入数量，不带产出数量 |

引用的决策编号：D26、D44、D56、D57；不变量：INV-16、INV-17；单据结构见 16，库存与库位见 04，计费事实见 08。

加工的内部工序、人员工时、良率统计不在本文范围：内部工序属现场管理，首期不做系统化。
