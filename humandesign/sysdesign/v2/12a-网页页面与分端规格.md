# 货灵 WMS Web 页面与分端规格

## 1 结论

Web 三端的页面归五类骨架，每端再按自己的使用者、输入方式与作业节奏取一套规格。共享的令牌、组件、文案与状态不在这里重复，只引用编号。

## 2 问题与范围

**解决**：页面结构各写一套、三端共用一套判断标准、端级差异靠实现者自己猜。

**不解决**：令牌、组件、文案、状态与反馈（见 `12-界面与交互设计规范.md`）；移动作业端原生 App（PDA 与安卓手机，见 `12b-移动作业端规格.md`）；路由、接口映射与权限点（见 change 的 `前端设计` 章）。

## 3 设计

### 页面骨架按用途固定

新增页面必须归入下列五类之一（列表、详情、表单、配置、打印），不得自行发明第六种结构。

**UI-P01 列表页**：页头（标题 + 主操作）→ 筛选区 → 批量操作条（选中行时出现）→ 表格 → 分页。顺序固定，筛选区不得移到表格下方。

**UI-P02 详情页**：整页详情仅用于需要独立链接分享或打印的场景，且须在页面规格写明原因；页头（标题、状态标签、操作）→ 分区卡片纵向排列，详情导航常驻并与正文联动（`UI-D02`、`UI-D03`）。从列表打开详情一律走侧拉抽屉（`UI-D01`），不新开独立详情路由页；两种详情外壳都按 `UI-C04`，页面只传数据与分区。

**UI-P03 表单页**：页头 → 分组表单 → 底部固定操作条（保存与取消右对齐）；长表单按业务分段，每段一个标题，不无限纵向堆叠。

**UI-P04 导航与画布**：顶栏高 56，左侧菜单展开 200、收起 64；内容区最小宽 1200、最大 1440 居中；最小支持分辨率 1366×768。

**UI-P05 货主端只到库区。** 页面不得出现库位号、Site 数量与部署位置（D17）；库存粒度为库区，默认不提供库位级筛选。

**UI-P09 配置页**：左侧树或列表（宽 240，可拖到 320）+ 右侧表单或详情区；左侧切换节点前若表单未保存必须提示；右侧未选中节点时显示引导，不显示空表单。适用于库区库位、包装规格、权限、设备型号能力等主数据配置。

**UI-P10 打印页**：固定版式容器，按纸张定宽（A4 210mm、面单 100×100mm 与 100×150mm）；屏幕预览与实际打印一致；打印时隐藏导航、按钮与轻提示，数据时间戳随内容保留；表格跨页重复表头；条码与二维码留足静区，不用图标字体承载关键信息。

包管理的包材、包装规格、包裹三类对象的页面要素，见 `12-界面与交互设计规范.md` 的 `UI-P06`~`UI-P08`。

### 三端各有一套规格，共享底座不重复

共享层（`UI-T`、`UI-C`、`UI-B`、`UI-W`、`UI-S`、`UI-F`、`UI-A`、`UI-X`）三端通用，不按端复制；本节只写每端特有的选择。

**主表：各维度横向对比**

| 维度 | 运营后台 | 货主端 | 单仓端 Web（含采集站） |
|---|---|---|---|
| 使用者与场景 | 运营、计费、客服，全天在岗，多任务并行 | 外部货主，短时查询与对账 | 现场作业员、仓管，站立或触摸操作 |
| 输入方式 | 键鼠，键盘流优先 | 键鼠 | 触摸 + 扫码枪，尽量不打字 |
| 信息密度 | 高，一屏尽量多行 | 中低，留白多 | 中，控件大 |
| 密度参数 | 见 `12-界面与交互设计规范.md` 数据密度节 | 同左 | 同左 |
| 导航 | 顶栏 + 多级侧边菜单 | 顶栏 + 一级菜单，无二级折叠 | 全屏任务式，无侧边菜单 |
| 交互节奏 | 批量、筛选、连续录入 | 查询、导出、打印 | 单步、扫码即走、强反馈 |
| 主操作位置 | 页头右侧或表格上方 | 页头右侧 | 屏幕底部固定 |
| 反馈强度 | 轻提示为主，失败带错误码 | 轻提示加解释，少术语 | 强反馈，成功与失败都看得见 |
| 文案语气 | 简洁专业，可用业务术语 | 礼貌、多解释，不暴露内部术语 | 极简，动作词为主，句子不超过一行 |
| 权限表现 | 功能权限 + 数据域 | 以数据域为主，入口按货主隐藏 | 角色 + 设备绑定 |
| 典型页面 | 列表、详情、表单、配置 | 列表、详情、打印 | 采集任务、打印、配置 |
| 最小分辨率 | 1366×768 | 1280×720 | 1024×768，触摸 |

**运营后台补充**

- 主流程必须能纯键盘完成：Tab 顺序、Enter 提交、Esc 取消、方向键在表格内移动
- 批量操作是常态，已选计数常显
- 允许高密度：默认每页 20 行，紧凑模式行高 32
- 业务术语可用，但必须与 `UI-W19` 术语表一致
- 多标签页并行是常态，筛选与选择不跨标签共享

**货主端补充**

- 不出现库位号、Site 数量与部署位置（D17），数据粒度只到库区
- 不出现内部角色名、内部流程术语、错误码原文；错误必须转成人话并给联系方式
- 默认只读；商品档案可创建、编辑、提交与停用，其余写操作只保留确有必要的（如预约、单据确认），且必须按异步受理表达
- 打印与导出是高频动作，入口固定在页头右侧
- 语气礼貌但简短，解释放进帮助提示，不铺在正文

**单仓端 Web 补充**

- 触摸优先：点击目标不小于 48×48，禁止悬浮才出现的操作、拖拽排序、右键菜单
- 扫码枪输入等同于键盘输入，扫码框常驻焦点，扫完自动提交
- 强反馈：成功与失败都要有颜色、文字与声音提示（声音可关闭）
- 单步作业：一屏只做一件事，作业页不叠加多层弹窗
- 采集站不出现需要精细指针操作的交互（`UI-C09`）
- 页面集合不按仓规模分两套：小仓与大仓共用同一套单仓端页面，入口按作业模式与权限显隐；被隐藏的页面直接访问仍受权限约束（见 00 D53）
- 作业从任务进入，不从单据进入：单据只在查询与追溯时作为聚合视图，不得做成小仓的作业入口（见 00 D55）

**UI-P11 同一业务在三端不要求页面一一对应。** 各端按自己的骨架与动线设计，不把一个端的页面结构直接套到另一个端。

**移动作业端不在本节**：动线、尺寸与反馈通道归 `12b-移动作业端规格.md`；跨端状态语义仍引用 `UI-T`、`UI-S`、`UI-F`，不得另造一套。

## 4 约束与验证

**强制手段**：页面评审对照 `UI-P` 编号与本文件主表；新增页面必须能归入五类骨架之一，并能说明属于哪一端、依据哪条端级补充。

**自检**：

1. 每个页面能归入 `UI-P01`~`P03`、`P09`、`P10` 之一，没有第六种骨架
1. 列表页详情走侧拉抽屉（`UI-D01`），整页详情有独立链接或打印的书面原因（`UI-P02`）
2. 每个页面能归到唯一的端，规格取自该端补充段
3. 货主端没有库位号、Site 信息、内部术语与错误码原文
4. 单仓端没有悬浮操作，点击目标不小于 48
5. 同一业务在三端可以页面不同，没有强行套用同一结构
6. 单仓端没有按仓规模拆出的第二套页面，入口显隐没有改变页面结构与接口
7. 单仓端作业入口是任务，不是单据；单据只出现在查询与追溯

**待确认**：采集站最小分辨率与端级品牌覆盖，见 `12-界面与交互设计规范.md` 的待确认表。
