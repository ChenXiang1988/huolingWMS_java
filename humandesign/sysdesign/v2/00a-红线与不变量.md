# 红线与不变量

## 1 结论

红线按「隔离、计价、账实、部署」四类分组，**每条只表达一个结论**；全局不变量是红线的强制落点，每条不变量必须有强制手段与验证方式。v1 把「无在途、模块化单体、强一致」三个独立结论塞进一条红线，本版拆开，使每条红线都能用一句话判定是否违反。

## 2 问题与范围

**解决**：不可违反什么、由什么强制、怎么判定违规。

**不解决**：决策的推导过程（`00`）、业务对象建模（卷二）、具体建表语句（`11`）、界面表现（卷四）。

## 3 设计

### 3.1 红线（四类，共十四条）

分类维度是「约束对象」：数据隔离、作业准入与计价、库存账实、部署与跨仓边界。四者互斥且穷尽——任何不可违反的约束，要么限制谁能看什么，要么限制能否作业与如何计价，要么限制账怎么记，要么限制系统在哪、货怎么跨仓；四类之外只剩由它们派生的实现规则，不属红线。

| 类别 | 编号 | 红线（一条一句结论） | 依据 |
|---|---|---|---|
| 隔离类 | R-01 | 货主是唯一隔离维度，不存在租户维度 | D01、D02、INV-06 |
| 隔离类 | R-02 | 所有货主同构，无内部与外部之分，无特权分支 | D03 |
| 隔离类 | R-03 | 货主开通即获全仓网访问权，不做仓级授权 | D40 |
| 计价类 | R-04 | 合同是计费唯一价源 | D32 |
| 计价类 | R-05 | 无生效合同不可作业 | D33、INV-12 |
| 计价类 | R-06 | 计费明细只能冲正，不能修改 | D36、INV-14 |
| 账实类 | R-07 | 库存必须绑定真实物理库位，禁止虚拟库位 | D26、INV-01 |
| 账实类 | R-08 | 库存状态与物理位置正交，不得互相表达 | D27 |
| 账实类 | R-09 | 库存扣减、分配、库位锁定在同一事务完成 | D09、INV-04、INV-11 |
| 账实类 | R-10 | 库存流水只追加、不可改删，且日结与台账对账 | INV-03、INV-09 |
| 部署类 | R-11 | 系统为模块化单体，不拆微服务 | D09 |
| 部署类 | R-12 | 每个仓一套独立部署、独立库与独立账号 | D08 |
| 部署类 | R-13 | 跨仓调拨无在途库存 | D14 |
| 部署类 | R-14 | 跨境只传摘要；关务与物流下层服务的结果只落单据观察区，不参与状态转换 | D07、D47、`15` |

**R-08 的待定边界**：「隔离」究竟表达为库位类型还是库存状态行，属决四，未拍板前不修改任何一侧的表述；拍板结果须同步本文件、`00` D27 与 D60、`04`、`21`、`22`，并记入 `log.md`。

### 3.2 全局不变量（INV-01 至 INV-19）

每条给出强制手段、所属红线与验证方式。编号只增不改。

| 编号 | 不变量 | 强制手段 | 所属红线 | 验证方式 |
|---|---|---|---|---|
| INV-01 | 所有库存绑定真实物理库位，库位类型枚举无虚拟值 | 非空约束、外键、枚举白名单 | R-07 | 建表检查 + 枚举登记核对 |
| INV-02 | 库位有物理坐标且现场可指认才可启用 | 启用态四段坐标非空；启用前扫码留痕 | R-07 | 启用流程用例 |
| INV-03 | 流水 `to_location_id` 永非空，`from_location_id` 仅外部入库可空 | 非空约束 + 事件类型检查 | R-10 | 建表检查 + 移库用例 |
| INV-04 | 库位容量不可超占，含已分配未执行 | 应用校验 + 库位行锁，分配与上架同事务 | R-09 | 并发上架用例 |
| INV-05 | 独占库位不得混货主 | 应用校验 + 库位行锁；日结核对 | R-01 | 越权与混放用例 |
| INV-06 | 货主是唯一隔离维度，不可绕过 | 仓储层统一注入货主条件，禁止手写 | R-01 | 越权测试 |
| INV-07 | 批次、序列号、容器不跨货主合并 | 唯一键含 `owner_id` | R-01 | 唯一键检查 |
| INV-08 | 分配只增 `qty_allocated`，不改变库存状态，且不超过在库量 | 数据库检查约束；应用校验不写状态字段 | R-09 | 分配用例 |
| INV-09 | 库存变动必留流水，流水不可改删，日结与流水对账 | 流水表只授插入；日结定时核对 | R-10 | 权限检查 + 对账任务 |
| INV-10 | 任务拆片携带已锁定库存切片，不重新分配 | 应用校验：结案时分片之和等于父任务分配量 | R-09 | 结案用例 |
| INV-11 | 已分配未执行的库存不得被他人上架挤占 | 应用校验 + 库位行锁，与 INV-04 共用同一把锁 | R-09 | 并发用例 |
| INV-12 | 无生效合同不可作业 | 受理前硬拦；单仓端合同缓存缺失即拒绝 | R-05 | 受理链路用例 |
| INV-13 | 计费按事实发生日匹配合同版本 | 按事实时间戳选版本；版本边界用例 | R-04 | 算费用例 |
| INV-14 | 计费明细只能冲正，不能修改 | 明细表不授更新与删除 | R-06 | 权限检查 |
| INV-15 | 每笔金额可回溯至事实、合同版本、规则与计算参数 | 四个字段非空约束 | R-04 | 回溯用例 |
| INV-16 | 在制库存必须落在真实工位库位，禁止在制池 | `location_id` 非空；库位类型为工位 | R-07 | 加工完工用例 |
| INV-17 | 加工投入减产出减损耗约等于零，损耗必须有去向 | 完工事务内平衡校验；容差在策略层配置 | R-10 | 加工平衡用例 |
| INV-18 | 数据不物理删除 | 业务表不授删除；逻辑删除标记 | R-10 | 权限检查 |
| INV-19 | 权限双重校验：功能权限加数据域权限 | 统一鉴权切面；越权用例 | R-01 | 越权测试 |

**本版新增的强制要求**：INV-03 必须在 `11` 的 `wms_stock_txn` 建表语句中体现起止库位两列（A-09）；INV-05 的强制手段只以本表为准，`04` 不得另写一套（A-24）；INV-10 的 `lock_id` 字段与生成时点见 `22`。

## 4 约束与验证

| 检查项 | 一句可判定语句 |
|---|---|
| 一条一结论 | 每条红线只含一个谓语，出现「并且」「以及」连接两个独立约束即拆分 |
| 红线覆盖 | 十四条逐条能指到至少一个 INV 或决策，无孤立红线 |
| 不变量闭合 | INV-01 至 INV-19 连续、无重号，每条都有强制手段、所属红线与验证方式 |
| 低层不越权 | 全库检索同一不变量的两套强制手段应为零命中 |
| 待定可见 | R-08 的未决状态在 `23` 待定项中有对应行 |
