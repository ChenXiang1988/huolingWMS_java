## 三、三条阅读路线

| 路线 | 面向 | 顺序 |
|---|---|---|
| 新成员 | 第一次接触 | 本索引 → `00` → `00a` → `21` → `22` → `23` → 按业务主题选读卷二 |

| 实现者 | 写代码与建表 | 本索引 → `21` 枚举 → `22` 状态与事务 → `23` 权威源 → `24` 功能清单 → `25` 场景 → 卷五落地文档 → 对应领域文档 |

三条路线互斥且穷尽：任何读者必属「初学、评审、实现」之一；跨路线时按上表顺序叠加，不另设第四条。

## 四、文档约定

1. **统一骨架**：每份文档为「结论 → 范围 → 设计（按互斥分组） → 约束与验证 → 引用与权威源」五章；结论章须能脱离后文独立作为评审判断。
2. **权威源顺序**：`00` 决策 → `00a` 红线与不变量 → `15` 边界 → 领域文档 → 落地文档 → 界面文档。低层不得推翻高层；确需推翻时先改高层、记入 `log.md`，再逐层同步。
3. **编号唯一**：编号只增不改、不复用；引用汇总清单须与正文逐条相符，校验规则见 `23`。
4. **枚举与状态**：枚举取值只查 `21`，状态词、状态转换与事务例外只查 `22`；任何文档不得另造。
5. **待定项**：全库唯一清单在 `23`，其他文档只引用、不另立待定表。
6. **变更留痕**：本目录每次改动记入 `log.md`；`v1/log.md` 已停止追加。
7. **与归档版的关系**：需要查「当初为什么这么定」时可回查 `../v1/00-decisions.md` 对应编号，但引用时必须标注「历史版本 v1，仅供溯源」。
