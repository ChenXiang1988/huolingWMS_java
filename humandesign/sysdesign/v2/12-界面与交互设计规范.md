# 货灵 WMS 界面与交互设计规范

## 1 结论

Web 三端（货主端、运营后台、单仓端的包管理与作业）共用一套交互与界面基线：每个操作按同一套闭环推进，同一动作与状态只有一个词，颜色与字号只有一个来源，页面骨架按用途固定，组件外壳只写一次，同一状态在任何端都用同一种视觉表达。执行时不得按页自造步骤、用词、颜色、间距与控件皮肤。

## 2 问题与范围

**解决**：操作步骤不闭环、失败无出口、同一动作多种叫法、状态词各页不同、跨页面视觉漂移、组件外壳重复实现、状态只靠颜色表达、三端密度混用、异常态各写一套。

**不解决**：页面清单与路由、页面到接口的映射、菜单与权限点（属 `frontend-design`）；业务规则判定（以服务端结果为准）；移动作业端原生 App（PDA 与安卓手机，属 `pda-design`）；Vue 组件实现与原型页面。

本规范只写 Web 三端：货主端、运营后台、单仓端的包管理与作业。移动作业端（PDA 与安卓手机）的动线与尺寸归 `12b-移动作业端规格.md`，跨端状态语义以本文件的 `UI-T`、`UI-S`、`UI-F` 编号为准。

## 3 设计

### 交互按任务闭环设计，不按页面堆功能

每个操作从入口到下一步形成闭环：入口 → 输入或扫码 → 校验 → 确认 → 提交 → 受理 → 结果 → 下一步。缺任一环不算设计完成。

| 编号 | 规则 | 规格 |
|---|---|---|
| UI-I01 | 任务闭环 | 八环齐全；写入类操作必须走到「结果」与「下一步」，不能停在提交 |
| UI-I02 | 步骤上限 | 普通表单不超过 3 步，批量作业不超过 2 次确认；超出改向导或批处理 |
| UI-I03 | 可点与禁用前置 | 前置条件不满足时置灰，并在按钮旁给一句原因；不做「点了才报错」 |
| UI-I04 | 二次确认 | 不可逆、影响他人、批量超过 20 条必须确认；确认框写清对象、数量、后果、主按钮文案 |
| UI-I05 | 防重复提交 | 提交中按钮禁用并显示行内进度；前端不生成业务单号 |
| UI-I06 | 失败出口 | 每个失败态给出「重试 / 修改输入 / 求助」至少一项，不出现无操作可做的页面 |
| UI-I07 | 中断恢复 | 离开未保存表单前提示；返回后恢复已填内容；从详情返回列表保留筛选、页码、排序 |
| UI-I08 | 批量结果 | 部分成功时分别列出成功与失败的条数和原因，失败项可单独重试 |
| UI-I09 | 键盘流 | 高频录入页 Enter 提交、Esc 取消；Tab 顺序与视觉一致；筛选变化后回到第 1 页 |
| UI-I10 | 空态引导 | 首次进入无数据时给一个可执行动作，不停在空白表格 |

**UI-I11 前端不做业务判定。** 合同是否生效、库存是否可用、库位能否上架，均以服务端返回为准，交互只呈现结果与出口（D16）。

**UI-I12 写入必须经过受理环。** 提交后先到「已受理」并展示受理号，再进入处理中，不得跳到结果（D20，规格见 `UI-F01`~`UI-F06`）。

### 文案按一套词表写，不按页面临时起名

同一个动作、同一个状态，在全系统只能有一个词。词表集中维护，页面不得自造同义词。

**UI-W01 通用动作词表。** 业务动作（收货、上架、拣货等）以领域词典为准，本表只管跨业务通用的界面动作。

| 动作 | 用 | 不用 | 适用位置 |
|---|---|---|---|
| 创建新对象 | 新建 | 新增、创建、添加 | 列表页主操作 |
| 改已有对象 | 编辑 | 修改 | 列表行操作、详情页 |
| 暂存不生效 | 保存 | 确定、应用 | 表单内 |
| 保存并触发流程 | 提交 | 保存、确定 | 表单底部主操作 |
| 放弃变更 | 取消 | 关闭、返回 | 表单内、弹窗次操作 |
| 关闭浮层 | 关闭 | 取消 | 抽屉与弹窗右上 |
| 二次确认 | 确认 | 确定、是 | 确认弹窗主操作 |
| 删除对象 | 删除 | 移除、清除 | 不可逆操作 |
| 对象失效但保留 | 停用 | 禁用、关闭 | 主数据 |
| 恢复可用 | 启用 | 开启、激活 | 主数据 |
| 批量进系统 | 导入 | 上传 | 列表页 |
| 批量出系统 | 导出 | 下载 | 列表页 |
| 纸质输出 | 打印 | 输出 | 打印页 |
| 重复纸质输出 | 重打 | 重新打印 | 面单 |
| 单据失效但留痕 | 作废 | 取消、删除 | 单据 |
| 以现有为模板 | 复制 | 克隆 | 主数据、规格 |
| 重新取数 | 刷新 | 重新加载 | 列表与详情 |
| 筛选恢复默认 | 重置 | 清空 | 筛选区 |
| 提交筛选 | 查询 | 搜索 | 筛选区 |
| 展开或收起 | 展开 / 收起 | 更多 / 收起 | 筛选区、详情 |

**UI-W02 一个动作只有一个词。** 不允许列表页写「新增」、详情页写「添加」；同一动作在按钮、提示、日志里用同一个词。

**UI-W03 按钮文案不超过四个汉字。** 超出改用短词或收进「更多」；不用标点，不用括号补充说明。

**UI-W04 单据状态用动宾式。** 统一为「待 + 动作」或「已 + 动作」，一眼看出下一步。

| 写法 | 示例 | 不用的写法 |
|---|---|---|
| 待办 | 待收货、待上架、待拣货、待复核、待发货 | 未开始、待处理、新建 |
| 已完成 | 已收货、已上架、已拣货、已复核、已发货 | 完成、已完成（重复） |
| 部分完成 | 部分收货、部分上架 | 收货中（含糊） |

请求态（受理中、处理中）与单据状态分开，不写进单据状态列表。通用终止态只有「已取消」「已作废」两个。

**UI-W05 状态词与枚举一一对应。** 一个枚举值对应一个中文词，映射集中在一处；同一枚举在所有页面显示同一个词；前端不拼接、不缩写。

**UI-W06 状态词不带标点与括号。** 「待收货（部分）」应拆成独立状态，不用括号补充。

**UI-W07 错误提示写三段：做什么失败、为什么、下一步怎么办。**

| 段 | 内容 | 示例 |
|---|---|---|
| 做什么 | 动作 + 对象 | 收货单提交失败 |
| 为什么 | 服务端给的原因 | 合同已过期 |
| 下一步 | 可执行动作 | 联系计费专员续签后重试 |

禁止单独出现「操作失败」「系统异常」「请稍后重试」。错误码放在第三段之后，用括号或独立一行。

**UI-W08 错误文案不指责用户。** 写「数量必须大于 0」，不写「您输入有误」。

**UI-W09 字段级错误只说规则。** 「必填」「最多 20 个字」「只能是数字」；不写「格式不正确」「输入有误」。

**UI-W10 空态写三段：没有什么、为什么、能做什么。**

示例：「暂无收货单 / 当前筛选条件下没有记录 / 清空筛选」。

**UI-W11 成功提示说结果，不说过程。** 写「收货单已受理，受理号 RC20261124001」，不写「提交成功」。

**UI-W12 二次确认写清对象、数量、后果。** 示例：「确认删除 3 条包装规格？删除后不可恢复。」主按钮用「删除」，不用「确认」。

**UI-W13 时间格式分三档。** 24 小时制，不使用上午/下午。

| 场景 | 格式 | 示例 |
|---|---|---|
| 列表 | `YYYY-MM-DD HH:mm` | 2026-11-24 14:30 |
| 详情与审计 | `YYYY-MM-DD HH:mm:ss` | 2026-11-24 14:30:05 |
| 仅日期 | `YYYY-MM-DD` | 2026-11-24 |
| 24 小时内 | 相对时间 | 3 分钟前、2 小时前 |

界面显示仓所在法域时间，接口传 UTC，转换集中在一处做（D38）。

**UI-W14 数字格式统一。** 四位以上加千分位（`10,000`）；小数位数按字段定义，界面不额外四舍五入；负数用负号，不用括号；百分比保留一位。

**UI-W15 数值与单位之间留一个半角空格。** 写「12 kg」「3 箱」「1,200 件」，不写「12kg」「3箱」。

**UI-W16 单号完整展示，不加工。** 不截断、不换行、不加千分位、不改大小写；列宽不够时悬浮显示全号；详情页单号后可复制；单号前缀由服务端返回，前端不拼接。

**UI-W17 金额出现时必须带币种。** 千分位加两位小数，符号或代码不省略；多币种同屏时必须显示币种代码。金额是否出现在界面见待确认。

**UI-W18 中英文之间留一个空格。** 写「共 12 条」「SKU 编码」；正文标点用全角，代码、路径、单号用半角；不用感叹号，不叠问号。

**UI-W19 术语固定，不混用同义词。**

| 用 | 不用 |
|---|---|
| 货主 | 客户、商家、租户 |
| 仓库 | 仓、站点 |
| 库区 | 区域、分区 |
| 库位 | 货位、储位 |
| SKU | 商品、产品、物料 |
| 批次 | 批号（字段名除外） |
| 单据 | 单子、作业单 |
| 任务 | 工单 |
| 包材 | 包装材料、耗材 |
| 包装规格 | 包装方案、包规 |
| 包裹 | 包、件 |
| 面单 | 标签、快递单 |

**UI-W20 不用口语与情绪词。** 可用「请」引导操作；不用「亲」「哦」「啦」，不用「抱歉」开头，直接说原因与出口。

### 令牌只从 Element Plus 派生，不另造一套

以 Element Plus 默认令牌为基线，页面只允许引用令牌名，不允许出现十六进制色值或自定义色阶。品牌主色暂沿用默认值，待品牌定稿后只改这一个令牌。

**首期不做视觉重设计。** 只允许覆盖主色 `UI-T01`，其余令牌沿用 Element Plus 默认；货主端如需对外品牌，也只覆盖主色，不改结构、间距与组件外壳。

| 编号 | 类别 | 令牌 | 值 | 允许用于 | 禁止用于 |
|---|---|---|---|---|---|
| UI-T01 | 主色 | `--el-color-primary` | `#409EFF`（沿用默认，品牌色待确认） | 主按钮、选中态、链接、焦点描边 | 表达业务状态 |
| UI-T02 | 成功 | `--el-color-success` | `#67C23A` | 已完成、可用、成功提示 | 普通强调 |
| UI-T03 | 警告 | `--el-color-warning` | `#E6A23C` | 待处理、临期、降级提示 | 失败与阻断 |
| UI-T04 | 危险 | `--el-color-danger` | `#F56C6C` | 失败、删除、冻结、隔离 | 普通说明文字 |
| UI-T05 | 信息 | `--el-color-info` | `#909399` | 辅助说明、禁用态 | 可点击元素 |
| UI-T06 | 正文 | `--el-text-color-primary` | `#303133` | 正文与关键值 | 大段说明 |
| UI-T07 | 次要 | `--el-text-color-regular` | `#606266` | 表格正文、表单值 | 页面标题 |
| UI-T08 | 辅助 | `--el-text-color-secondary` | `#909399` | 标签、单位、时间 | 关键结论 |
| UI-T09 | 占位 | `--el-text-color-placeholder` | `#A8ABB2` | 占位符、禁用文本 | 需要阅读的内容 |
| UI-T10 | 边框 | `--el-border-color` | `#DCDFE6` | 控件边框、表格外框 | 行分隔线（用 `UI-T23`） |

**UI-T11 语义色只表达结果，不表达判断。** 合同是否生效、库存是否可用、库位能否上架，颜色只呈现服务端给的结果，不承担推断。

**UI-T12 字号阶梯固定七档**：32 / 24 / 20 / 16 / 14 / 13 / 12。正文 14，表格 14，辅助信息 13，最小 12。不出现 15、18 这类中间值。

**UI-T13 行高固定为字号的 1.5 倍**，表格行高单独按 `UI-C01` 执行。

**UI-T14 间距只取 4 的倍数**：4 / 8 / 12 / 16 / 24 / 32 / 48。页面外边距 24，卡片内边距 16 或 24，表单控件纵向间距 16。

**UI-T15 圆角三档**：控件 4，卡片与抽屉 8，标签与徽标 4。不使用胶囊形与全圆角，头像除外。

**UI-T16 阴影只用 Element Plus 三档**（`--el-box-shadow-light` / `base` / `dark`），不自定义阴影。

**UI-T17 层级固定**：固定顶栏 1000，下拉与浮层 2000，弹窗 2001，抽屉 2002，全局提示 3000。不得出现自定义 `z-index`。

**UI-T18 动效固定**：进入 200ms、退出 150ms，缓动 `ease-out`；系统开启「减少动效」时取消位移与缩放，只保留透明度。

**UI-T19 图标只用 Element Plus 图标集**，尺寸 16 / 20 / 24 三档；图标不得单独承担语义，必须配文字或 `aria-label`。

**UI-T20 背景分三层。** 页面级、容器级、浮层级底色不得混用。

| 场景 | 令牌 | 值 | 令牌条目 |
|---|---|---|---|
| 内容区底层 | `--el-bg-color-page` | `#F2F3F5` | `UI-T20` |
| 卡片、抽屉、弹窗 | `--el-bg-color` | `#FFFFFF` | `UI-T20` |
| 下拉与浮层 | `--el-bg-color-overlay` | `#FFFFFF` | `UI-T20` |
| 遮罩 | `--el-overlay-color-lighter` | `rgba(0, 0, 0, 0.5)` | `UI-T20` |

**UI-T21 填充只表达交互态。** 表头、悬浮、选中、分组、禁用、只读各用一个令牌，不得用边框或阴影替代底色。

| 只读控件底 | `--el-fill-color-lighter` | `#FAFAFA` | `UI-T21` |

**UI-T22 主色衍生只用四档。** 悬浮、按下、选中底、浅边框各一档，不自造中间色。

**UI-T23 边框分三级。** 控件、分隔线、强调各一级，不交叉使用。

### 基础组件只定用法，不定外观

Element Plus 提供外观与基础行为，本节只定本项目允许哪些变体、放在哪、多大。页面不得改造组件内部结构。

**UI-C10 文本输入只用于单行。** 多行内容用文本域，不用单行输入撑高；长度上限按字段定义；清除按钮只出现在搜索框。

**UI-C11 数字输入右对齐，单位外置。** 数量、重量、体积的小数位按字段定义，界面不额外截断或补零；单位固定在输入框右侧，不放进输入值里。

**UI-C12 日期范围固定三个快捷项。** 今天、近 7 天、近 30 天；选择精确到分，需要秒时在详情与审计区显示（`UI-W13`）；不提供相对时间选择器。

**UI-C13 选项超过 10 条用可搜索下拉。** 多选标签超过 3 个折叠为「+N」；不使用原生下拉；下拉宽度不窄于触发器。

**UI-C14 开关只用于立即生效的设置。** 需要点保存才生效的用单选或复选；开关旁必须有文字说明当前状态。

**UI-C15 详情字段用描述列表。** 两列或三列，标签宽度固定 100 或 120，与表单一致；值超长换行，不横向滚动。

**UI-C16 折叠面板默认展开第一项，最多 5 个。** 超过 5 个改用标签页或配置页左树。

**UI-C17 时间线只用于有先后顺序的留痕。** 状态流转、操作记录可用；普通列表不用。

**UI-C18 进度分确定与不确定。** 有总量的用进度条并显示百分比；无总量的用 spinner；不显示假进度。

**UI-C19 树用于层级主数据，超过 200 节点启用懒加载。** 库区库位、权限、组织用树；节点文案超长省略并悬浮显示。

**UI-C20 标签页用于同一对象的不同视图，最多 6 个。** 超过 6 个改用侧边导航；标签页不跨路由复用筛选状态。

**UI-C21 统计数值只出现在看板与汇总区。** 主数字 32 号、600 字重；单位比主数字小两档；不做千分位以外的修饰。

**UI-C22 气泡确认只用于轻量操作。** 停用、启用、复制用气泡；删除、作废、批量操作仍用弹窗（`UI-C05`）。

**UI-C23 通知只用于异步任务完成。** 右上角，停留 5 秒可关闭；不用通知承载错误，错误按 `UI-S04` 就地显示。

**UI-C24 骨架屏只用于首次加载。** 刷新与轮询不用骨架屏，避免闪烁；骨架形状与真实内容一致。

**UI-C25 结果页只用于长流程结束。** 向导、批量导入、批量作业结束用整页结果；普通表单提交按 `UI-F01`~`F03` 处理，不跳结果页。

### 业务组件复用同一外壳，只换数据源

**UI-B01 选择器只有一套外壳。** 货主、SKU、库位、批次、单据五类选择器共用同一结构，只换数据源、展示列与筛选条件。

| 部位 | 规格 |
|---|---|
| 触发器 | 输入框样式，右侧搜索图标；已选显示名称加编码；超宽省略，悬浮显示全称 |
| 弹层 | 搜索框 + 结果表格 + 分页；远程搜索，输入防抖 300ms |
| 多选 | 标签堆叠，超过 3 个折叠为「+N」，悬浮展开 |
| 加载 | 搜索中显示行内 spinner，不清空已有结果 |
| 空态 | 「无匹配结果」，不出现空白弹层 |
| 清空 | 悬浮显示清除按钮，一键清空已选 |
| 键盘 | 上下键移动，Enter 选中，Esc 关闭 |
| 回显 | 编辑场景按标识回显名称，不把标识直接显示给用户 |

**UI-B02 货主选择器。** 数据范围由当前用户的数据域决定；显示「货主名称 + 编码」；只读场景用文本，不用选择器。

**UI-B03 SKU 选择器。** 支持编码、名称、条码三种搜索；结果列：编码、名称、规格、单位、条码；多选上限由调用方传入，超出时就地提示。

**UI-B04 库位选择器。** 按仓库 → 库区 → 库位逐级选择；显示「库区 / 库位编码」；**货主端不出现**（D17）；不可用库位置灰并给原因。

**UI-B05 批次选择器。** 先按 SKU 过滤再选批次；结果列：批次号、生产日期、到期日；到期状态按服务端返回标记，前端不自行计算临期。

**UI-B06 单据选择器。** 按单据类型过滤；结果列：单号、类型、状态、日期；可选状态由服务端返回，不可选置灰并说明原因。

**UI-B07 选择器不承担业务校验。** 可选范围、可用量、能否操作，全部以服务端返回为准；前端只按返回结果呈现可选与不可选，不自行推断（D16）。

**UI-B08 单据号展示件。** 单号加复制图标；超宽不换行，中间省略，悬浮显示全号；可跳详情时整号可点；不做大小写、分隔符或前缀加工（`UI-W16`）。

**UI-B09 审计信息区。** 固定在详情页底部或抽屉最后一屏；字段为创建人、创建时间、最后修改人、最后修改时间；时间按 `UI-W13` 的详情档到秒；未修改过时只显示创建信息，不显示空的修改行。

**UI-B10 业务状态到标签的映射集中一处。** 一个枚举对应一个中文词与一种语义色，颜色只分四组：进行中、已完成、异常、终止；前端不按字符串包含判断状态。

**UI-B11 扫码输入框 Web 端共用。** 采集站与运营后台同一组件；采集站模式下常驻焦点、扫码即提交、成功后清空并保持焦点、失败保留内容并就地提示；手工录入需显式切换并打标记（D25、`UI-F06`）。

**UI-B12 附件上传与预览。** 大小上限与格式白名单由服务端返回，界面显示上限与允许格式；上传中显示进度，失败可重试；图片可预览，PDF 新窗口打开；不提供在线编辑。

**UI-B13 打印预览件。** 预览区加打印按钮，版式按 `UI-P10`；纸张规格由调用方传入；打印前校验必填项（如面单号）并就地提示；不显示假进度条。

### 包管理按三个对象分界面

包管理在仓库涉及三类对象：包材、包装规格、包裹。三者性质不同，界面不得混成一个混合列表。

| 编号 | 对象 | 是什么 | 页面要素 | 关键交互 |
|---|---|---|---|---|
| UI-P06 | 包材 | 纸箱、气泡膜、胶带、托盘、冰袋等耗材与容器 | 台账（名称、规格、单位、可用量、补货阈值）+ 领用记录 | 领用、低于阈值提示、停用；可用量以服务端为准 |
| UI-P07 | 包装规格 | 某类商品怎么包的方案：包材组合、用量、装箱数、层数、特殊要求 | 方案列表 + 明细（包材与用量）+ 绑定范围 + 启停用 | 新建版本、复制、停用；停用不影响历史包裹 |
| UI-P08 | 包裹 | 一次实际打包的结果：包裹号、关联单据、内含明细、重量体积、面单状态 | 包裹列表 + 打包作业页 + 面单打印 | 称重、封箱、打印或重打面单、异常处理 |

**UI-I13 三类对象不合并页面。** 包材是耗材，包装规格是方案，包裹是事实；列表、详情、筛选各用各的页面，不做「包管理」混合页。

**UI-I14 规格引用包材，包裹引用规格。** 包装规格的明细从包材台账选；打包页按规格展示所需包材与用量。实际消耗与扣减以服务端结果为准，界面不做本地增减。

**UI-I15 包裹与单据只展示不推断。** 关联单据的类型、编号、面单状态由服务端返回，界面不自行合并、拆分或补齐。

**UI-I16 移动作业端上的打包作业归 12b 号规范。** 本节只定 Web 端（含固定式采集站）的包管理界面与交互。

### 数据密度按端分档

三端各用一档，同一端内不得混用两档。

| 端 | 控件高度 | 表格行高 | 正文字号 | 页面边距 | 取向 |
|---|---|---|---|---|---|
| 运营后台 | 32 | 40（紧凑 32） | 14 | 24 | 高密度录入与核对，键盘优先 |
| 货主端 | 40 | 48 | 14 | 32 | 舒适阅读，只读为主 |
| 固定式采集站 | 48 | 56 | 16 | 24 | 触摸与强反馈，少输入 |

**UI-C09 采集站不出现需要精细指针操作的交互**：拖拽排序、悬浮才出现的操作、小于 48 的点击目标一律禁用。

### 五种状态必须双编码

状态一律「颜色 + 文字」或「颜色 + 图标」，不得只靠颜色区分。

| 编号 | 状态 | 触发 | 视觉 | 文案 | 出口 |
|---|---|---|---|---|---|
| UI-S01 | 加载 | 请求超过 300ms | 列表与详情用骨架屏，按钮内用行内 spinner | 「正在加载」 | 无 |
| UI-S02 | 空数据 | 结果为 0 | 120px 插画 + 主文案 + 次文案 | 「暂无数据」+ 原因（无记录 / 筛选过窄） | 新建、清空筛选 |
| UI-S03 | 无权限 | 403 或数据域为空 | 整页插画 + 说明 | 「无权访问」+ 需联系的角色 | 返回上一页 |
| UI-S04 | 接口失败 | 请求失败 | 区域内错误块，不整页白屏 | 错误码 + 人话说明 | 重试 |
| UI-S05 | 降级数据 | 走 Hub 副本（D19） | 顶部 32px 提示条，警告色 | 「数据时间：YYYY-MM-DD HH:mm」 | 刷新取实时 |

**UI-S06 错误码必须展示在界面上**，便于用户报障；不得只显示「系统繁忙」。

**UI-S07 降级提示条常驻到刷新成功**，不自动消失；同页多个降级数据源只显示一条，取最早的数据时间。

### 异步受理与反馈按同一套节奏

| 编号 | 场景 | 表达 |
|---|---|---|
| UI-F01 | 写入提交 | 进入「已受理」，展示受理号；**不得显示「成功」**（D20） |
| UI-F02 | 处理中 | 状态标签「处理中」；每 3 秒轮询，最长 60 秒；超时转「稍后查看」并给查询入口 |
| UI-F03 | 结果到达 | 成功或失败整条替换状态；失败给重提入口，保留原输入 |
| UI-F04 | 轻提示 | 成功 2 秒自动消失；失败 4 秒且可手动关闭；失败提示必带错误码 |
| UI-F05 | 危险操作 | 二次确认；批量操作在确认框内显示影响条数；删除类需要输入名称确认 |

**UI-F06 扫码校验的瞬时态**：显示「校验中」，校验失败在扫码框下方就地回显原因，不弹整页错误（D25）。

### 跨页行为统一，不留给页面自己定

**UI-X01 批量选择默认不跨页保留。** 翻页即清空已选，表头全选只作用于当前页；需要跨页时勾选「跨页全选」，并显示总条数、二次确认后才能执行。

**UI-X02 批量操作前回显范围。** 确认框写「对已选 12 条执行 XX」，不写「确定执行吗」；部分成功按 `UI-I08` 展示失败项。

**UI-X03 列配置可由用户调整，至少保留一列。** 可改显示与隐藏、顺序、列宽；勾选列与操作列不可隐藏；提供「恢复默认」。保存位置默认本地，是否存服务端见待确认。

**UI-X04 筛选、排序、页码写入 URL。** 刷新、分享、浏览器回退都能还原；从详情返回列表保持原条件与原页码；不跨会话保留。

**UI-X05 会话超时前必须预警。** 剩余 5 分钟提示并可续期；到期跳登录，登录后回到原页面并恢复筛选；提交中的表单本地暂存，重新登录后可恢复。超时时长见待确认。

**UI-X06 权限不足分两种表现，不混用。**

| 情况 | 表现 |
|---|---|
| 无功能权限 | 入口不渲染，菜单与按钮都不出现；不置灰 |
| 有功能权限、无数据域 | 页面可见，数据为空，按 `UI-S03` 显示无权限说明与联系人 |

业务前置条件不满足时才置灰并给原因（`UI-I03`），权限不足不置灰。

**UI-X07 导入分三步，先校验后受理。**

1. 下载模板，模板不带当前筛选条件
2. 上传后先做必填与格式校验，显示总行数、通过数、失败数
3. 失败行可下载并带原因列，修正后重新上传

提交后进入异步受理，给批次号与查询入口；本次是新增还是覆盖由服务端规则决定，界面必须显式提示，不让用户猜。

**UI-X08 导出是异步任务。** 提交后给任务号，不阻塞当前页面；完成后提示并落到下载中心；导出遵循当前筛选与排序。

**UI-X09 下载中心统一承接生成物。** 导出文件、导入失败行、打印文件都在这里取；显示生成时间与过期时间；过期文件不可下载，提示重新生成。

**UI-X10 返回列表必须还原上下文。** 筛选、页码、排序、滚动位置至少保留前三项；浏览器返回与页面内返回行为一致。

**UI-X11 刷新只作用于当前区域。** 列表页刷新表格不清筛选；详情页刷新当前单据不跳回列表；自动轮询不打断用户正在输入的表单。

**UI-X12 版本冲突不自动覆盖。** 服务端返回版本冲突时，提示「该单据已被他人修改」，给「刷新查看」与「放弃本次修改」两个出口，不静默重试、不覆盖。

### 可访问性有最低线

**UI-A01** 正文文字与背景对比度不低于 4.5:1，20 号以上大字不低于 3:1。

**UI-A02** 键盘焦点必须可见，2px 主色描边，不得用 `outline: none` 去掉。

**UI-A03** Tab 顺序与视觉顺序一致；Esc 关闭浮层，Enter 触发主操作；提交中禁用重复提交并保持焦点。

**UI-A04** 触摸热区不小于 48×48（采集站）；运营后台主操作不小于 40×40，次要图标按钮不小于 32×32。

**UI-A05** 表单错误同时给出颜色、图标与文字，并通过 `aria-describedby` 关联控件。

### 三端各有一套规格

共享底座三端通用；分端主表、各端补充与 `UI-P11` 写在 `12a-网页页面与分端规格.md`，本节不重复。

## 4 约束与验证

**强制手段**：本阶段靠文档评审，任何页面设计对照 `UI-*` 编号逐条核；进入实现阶段后收敛为组件库封装，业务页面不得直接写颜色、间距与 `z-index`。

**自检**：

1. 每个操作都有完整闭环，没有停在「点提交」
2. 每个失败态都有出口，没有无操作可做的页面
3. 不可逆与批量操作都有二次确认，重复提交有拦截
4. 页面归入 `UI-P01`~`UI-P03`、`UI-P09`、`UI-P10` 之一，没有第六种骨架
5. 业务页面只引用令牌名，十六进制色值只出现在令牌定义表里
6. 字号、间距、圆角、层级全部落在阶梯内
7. 五种状态都有双编码，没有只靠颜色的表达
8. 写入交互都是「已受理」，没有提交即成功
9. 货主端无库位号与 Site 信息
10. 采集站没有精细指针操作，点击目标不小于 48
11. 抽屉沿用 `UI-C04`，没有另写外壳
12. 包管理三类对象各有独立页面，没有混成一个列表
13. 按钮与状态用词来自词表，没有同义词混用
14. 错误提示三段齐全，没有「操作失败」这类空话
15. 批量选择有范围回显，跨页全选需确认
16. 返回列表能还原筛选、页码与排序
17. 每个页面能归到唯一的端，规格取自该端补充段
18. 货主端没有内部术语、库位号与错误码原文
19. 单仓端没有悬浮操作，点击目标不小于 48
20. 五类选择器共用同一外壳，没有各写一套
21. 单据号未被截断、改写或拼接
22. 审计区字段齐全，未修改过时不显示空行
23. 基础组件只用 Element Plus 的变体，没有自造控件
24. 开关只用于即时生效项，需要保存的用单选或复选
