# PDA 采购与验收

抓取时间 2026-11-24。证据规则见 [00-调研方法与模板](./00-调研方法与模板.md)，机型参数见各品牌报告，横向对比见 [README](./README.md)。

## 结论

采购按"一组数值 + 一张台账 + 十二项验收"执行：低于下限不进入比价，能力只按台账枚举登记，到货逐台做验收，不做抽检。

## 问题

解决：采购按什么数值卡、到货怎么验、能力怎么写进台账（00 D22）。
不解决：供应商谈判、价格审批、维修工单与固资（属 EAM）。

## 设计

### 采购下限是一组数值，不是"工业级"三个字

| 项 | 下限 | 优先 | 依据 | 强制手段 |
|---|---|---|---|---|
| 操作系统 | Android 13 | Android 14 及以上 | 01 的 minSdk 26 是兼容底线，采购要覆盖换机周期 | 采购准入表 + 到货核验 |
| 内存与存储 | 4GB + 64GB | 6GB + 128GB | 原生应用 + 扫码服务 + 打印服务常驻 | 到货核验 |
| 屏幕 | 4 英寸、800×480、350nit | 450nit 以上、支持手套与湿手 | 强光月台与冷库门口 | 现场目视 + 触控测试 |
| 键盘 | 29 键以上数字键盘 + 2 个扫描键 | 38 键或 47 键 | 数量与批次号手输兜底 | 到货核验 |
| 扫描 | 一维/二维影像式，3mil 以上 | 近远双引擎或远距 10 米以上 | 货架高度与标签密度 | 现场实测 |
| 电池 | 5000mAh，可拆卸 | 支持热插拔换电 | 单班 8 小时以上，换电不停机 | 到货核验 + 续航测试 |
| 防护 | IP65，1.5 米跌落 | IP67/IP68，1.8 米跌落 | 仓内跌落与粉尘 | 样机跌落测试 |
| 工作温度 | −20℃ 至 50℃ | 冷链另配 −25℃ 及以下机型 | 月台与冷库门口温差 | 采购准入表 |
| 无线 | Wi-Fi 5、双频、支持 802.11r/k/v | Wi-Fi 6/6E、2×2 双流 | 跨 AP 漫游时的请求抖动（00 D16） | 现场漫游测试 |
| 蓝牙 | 5.0，支持低功耗 | 5.1 及以上 | 蓝牙秤与标签打印机 | 外设联调 |
| 重量 | 直板 320g 以内 | 枪柄 550g 以内 | 8 小时班次的手臂负担 | 到货核验 |
| 扫码输出 | 广播或厂商 SDK | 两者都支持 | 见下一节 | 技术验证 |

**强制手段**：任一项低于下限即不进入比价；例外只能由冷链或防爆机型单独申请，并在台账标注例外原因。

### 系统版本要比 minSdk 高，而且写进合同

01 定的 minSdk 26 是"应用能装上的最低版本"，不是"该买的设备版本"。两者差 5 个大版本：

- 国产在售机型仍集中在 Android 11 至 13，东集 Q7-(S) 还停在 Android 9；
- 防爆与冷链机型普遍落后一代：优博讯 DT50 Ex 为 Android 11，东集 Q7 Cold 官网未标；
- 厂商官网普遍不写安全补丁年限，只能靠合同约定。

**强制手段**：合同写明"交付时不低于 Android 13，且厂商承诺自交付日起至少两个大版本升级或五年安全补丁"；达不到的走例外审批，台账记录到期换机时间。

### 扫码结果必须走广播或 SDK，键盘模拟只能做兜底

| 输出方式 | 原理 | 稳定性 | 适用 |
|---|---|---|---|
| 广播（Intent） | 扫描服务发系统广播，应用注册接收器解析 | 高，与界面解耦 | 本项目主通道 |
| 厂商 SDK | 绑定扫描服务，回调拿结果，可调参数、读错误码 | 最高，但一厂商一套 | 本项目主通道 |
| 键盘模拟 | 结果逐字符注入当前焦点输入框 | 低，抢焦点、丢特殊字符、弹窗误填 | 仅调试与应急 |

**实证依据**：新大陆官方手册写明其接口基于标准 Android 广播机制、无需额外 SDK【实证】；优博讯提供统一 SDK 与 ScanWedge 数据加工【实证·官网】；盈达提供 iScan API 与 Device API【实证·官方彩页】。

**强制手段**：应用内做一层扫码适配，按机型加载实现，业务代码只接收码值与码制；上线前禁用键盘模拟通道。

### 无线按漫游验收，不按峰值速率

| 指标 | 要求 | 说明 |
|---|---|---|
| 频段 | 2.4G + 5G 双频 | 只支持 2.4G 在货架密集区丢包明显 |
| 漫游协议 | 802.11r/k/v 至少支持 r 与 v | 快速切换与拓扑感知 |
| 天线 | 2×2 双流优先 | 金属货架环境抗衰减 |
| 蜂窝 | 常温仓可不配，月台与场站建议 4G/5G | 漫游失败时的兜底通道 |

**强制手段**：现场跨 AP 走动 50 次，记录扫码校验失败次数与单次重连时间；阈值由 Site 侧校验接口时延目标给定，未通过不批量采购。

### 电池与班次绑定：能换电比容量大更重要

| 项 | 要求 | 理由 |
|---|---|---|
| 容量 | 5000mAh 起 | 单班 8 小时连续扫码的基线 |
| 换电 | 可拆卸，热插拔优先 | 中途换电不能中断当前作业会话 |
| 备电 | 每台 1 块 | 否则换电即停机 |
| 座充 | 按 1:4 配四联或五联座充 | 集中充电与版本下发同点位 |
| 低温 | 冷链机用低温电芯 | 常温电池在 −25℃ 掉电陡增 |

**强制手段**：到货做一次不关机换电实测；备电与座充写进采购清单。

### 环境适应按仓型给数值

| 仓型 | 防护 | 跌落 | 工作温度 | 额外 |
|---|---|---|---|---|
| 常温 | IP65 起 | 1.5 米起 | −20℃ 至 50℃ | 手套与湿手触控 |
| 冷链 | IP65 起 | 1.5 米起 | −25℃ 起，优先 −30℃ | 屏幕与扫描窗加热、抗冷凝、低温电池 |
| 危化 | IP65 起 | 1.5 米起 | −20℃ 至 50℃ | 本安防爆认证；禁拍照机型须可关断相机 |
| 保税 | 同常温 | 同常温 | 同常温 | 海外场站确认谷歌服务与频段 |

**注意**：IP 等级高不等于耐摔，跌落与滚筒是两套测试；"1.8 米"多为六面各若干次落到混凝土或大理石，验收以样机实测为准。

### 外设只在需要时选配

| 外设 | 何时需要 | 接口 | 备注 |
|---|---|---|---|
| 蓝牙电子秤 | 收货称重、加工投料 | 低功耗蓝牙 | 应用内做断连重连 |
| 蓝牙标签打印机 | 上架标签、库位标签 | 低功耗蓝牙 | 打印失败可重打并留痕 |
| 超高频 | 批量盘点、整箱复核 | 内置、背夹或手柄 | 内置读距短（米级），背夹远但重 |
| 近场通信 | 员工卡、设备卡 | 13.56MHz | 00 D23 已定登录只验员工身份 |
| 摄像头 | 异常取证、签收拍照 | 内置 | 危化区须可禁用 |
| 一键对讲 | 月台与库内协同 | 内置 | 非必需，增加重量与成本 |

**强制手段**：设备台账按"扫码 / 超高频 / 打印 / 低温 / 防爆"五项能力登记（00 D22），外设按能力组合领用。

### 台账字段与到货验收：设备管理只认这两张表

| 台账字段 | 取值 | 来源 |
|---|---|---|
| 设备类别 | 常温按键机 / 常温大屏机 / 冷链机 / 防爆机 | 采购单 |
| 扫码能力 | 一维 / 二维 / 远距 / DPM | 采购规格 |
| 超高频 | 无 / 内置 / 背夹 / 手柄 | 采购规格 |
| 打印 | 无 / 蓝牙打印 | 实测 |
| 低温 | 常温 / −25℃ / −30℃ | 采购规格 |
| 防爆 | 无 / `Ex ib IIC T4 Gb` | 防爆证书编号 |
| 键盘 | 全触屏 / 29 键 / 38 键 / 47 键 | 采购规格 |
| 系统 | Android 大版本与补丁日期 | 首次开机实测 |
| 管理通道 | 厂商平台 / 第三方 MDM | 实测 |
| 状态 | 在线 / 电量 / 应用版本 | 应用上报 |

到货验收逐台做，不做抽检：

| # | 验收项 | 通过标准 |
|---|---|---|
| 1 | 连续扫码 | 100 次连续扫描无失败，含污损、弯曲、屏幕码各 20 次 |
| 2 | 最小密度 | 3mil 条码在 20cm 内一次读出 |
| 3 | 远距读码 | 最高货架层实测可读（仅远距机型） |
| 4 | 跨 AP 漫游 | 走动 50 次，扫码校验失败次数与重连时间达标 |
| 5 | 冷库往返 | −25℃ 放置 30 分钟后回常温，镜头起雾恢复时间可接受（仅冷链机） |
| 6 | 手套操作 | 1.5mm 手套下完成扫码、按键、确认三步 |
| 7 | 湿手操作 | 手部带水下触控有效 |
| 8 | 跌落 | 样机 1.5 米六面跌落后功能正常 |
| 9 | 不关机换电 | 热插拔换电后当前任务与登录态不丢 |
| 10 | 续航 | 连续扫码加屏幕常亮不低于 8 小时 |
| 11 | 外设联调 | 蓝牙秤、打印机配对与断连重连正常 |
| 12 | 纳管 | 平台可远程安装、锁屏、读取电量与版本 |

**强制手段**：12 项全过才入台账；任一项不过整批退回，不做"先用着再说"。

### 每仓配比与备件：按峰值人数算

| 项 | 配比 | 说明 |
|---|---|---|
| 作业机 | 峰值同时作业人数 × 1.2 | 含 15% 至 20% 备机 |
| 大屏机 | 每仓 1 至 2 台 | 班组共用 |
| 座充位 | 作业机数量 ÷ 4 上取整 | 集中充电点同时是版本下发点 |
| 备用电池 | 每台 1 块 | 换电不停机的前提 |
| 保护套与钢化膜 | 1:1 | 跌落指标多在带套条件下测得 |
| 备件库存 | 整机 5%、电池 20% | 冷链与防爆单独备 |

**强制手段**：配比写进仓型能力矩阵（07 号文档）；备件低于下限由设备台账告警。

## 约束与验证

| 约束 | 强制手段 |
|---|---|
| 设备类别必须与仓型匹配 | 台账枚举校验 + 采购准入表 |
| 采购参数不得低于下限表 | 采购准入表逐项签字，缺项退回 |
| 安卓版本与补丁承诺入合同 | 合同条款 + 到货核验 + 到期换机提醒 |
| 扫码不得依赖键盘模拟 | 技术验证 + 验收逐台确认 |
| 漫游必须现场实测 | 验收单归档，未过不批量采购 |
| 台账能力字段只从固定枚举取值 | 数据库约束 + 与采购单对账 |
| 同仓型单一型号 | 型号变更走审批并更新备件计划 |
