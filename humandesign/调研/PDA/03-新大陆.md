## 2. 它是什么 / 不是什么

以识读技术起家的厂商，扫码头与整机都做，按键机是它的传统强项。N7 是本次国产按键机里参数最齐的一台。

不是：大屏机主推厂商（在售线以 4 英寸按键机与轻量机为主）；也不是只卖整机（提供 NQuire 开发接口与配置手册）。

## 4. 系统版本与生命周期

N7 同时有 Android 11 与 13 两个批次在售，页面并列标注"Android 11/13"，**下单必须指定 13**，否则可能拿到旧批次。

MT90 为入门线（京东标 4+64G、5 英寸、八核），系统版本未取证，不作为工业主设备考虑。

## 5. 扫码与开发接口

官方 NQuire API 手册写明：所有接口基于标准 Android 广播机制，**无需额外 SDK**；可直接把数据填入输入框，或模拟键盘输出【实证·官方手册】。

这条对应用层最有利：广播通道跨品牌兼容性最好，键盘模拟仅作兜底。手册同时提供码制配置与 API 说明，属于国产厂商里文档较完整的一家。

## 10. 对本项目的结论

N7 满足标准作业机的全部硬指标：4 英寸、29/47 键、5100mAh 热插拔、IP65、1.8 米、Wi-Fi 5 且支持 11k/r/v、380g。近远双引擎版还能覆盖高位货架。

建议：N7（指定 Android 13）作为常温标准作业机主选之一；冷库场景要求厂商书面确认整机温度与镜头加热配置后再采购。

## 11. 不建议的部分

- 不指定系统版本下单：N7 有 Android 11 批次在售。
- 冷库场景只看"电池 −30℃"就下单：整机工作温度仍写 −20℃ 至 50℃，两者不是一回事。
- MT90 做工业主设备：入门定位，参数未取证。
