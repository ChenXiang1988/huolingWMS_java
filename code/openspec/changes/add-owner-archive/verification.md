## 3. 已实测的关键行为

### 主数据与状态

- 建档生成 `OW` 编号、四项必填缺失即拒、信用代码重复即拒、名称可重复
- 停用阻断新建、存量单据可继续、停用不自动恢复（迁移重跑与定时任务均不恢复）
- 库层约束实测：四项 NOT NULL、信用代码唯一（停用档继续占位）、编号与主键不可变、只放行两条状态迁移、删除被触发器拒绝、清空被语句级触发器拒绝

### 接口与契约

- API-020 至 API-027 全部按契约返回；写接口 202 受理，受理号隔离（API-027 只认 023 至 026）
- 契约产物对账 28 条：写接口 202、错误码齐备、请求体字段正确、`lastStatusChange.action` 三值、API-020 无 `dataTimestamp` 与旧参数声明
- 幂等与并发：同键十并发只有一条档案与一个受理号、同键异体冲突、处理中可重试、版本冲突与停用态改档分别有码
- 数据域：列表、详情、写接口、受理查询四处均收窄；域为空拒绝；货主端令牌访问八个接口全部被拒
- 限流与降级：打满查询不影响写入；权限判定不可用返回 503，不返回空数据

### 账号与登录

- 货主端账号授 `OWNER_USER` 后可登录并调通货主端接口；货主端账号挂运营端角色被拒、运营端账号挂货主角色被拒，均不建账号
- 绑定后不可改（应用层与库层触发器双重）
- 货主停用后登录失败，已建会话下一请求 401，刷新令牌被撤销

### 停用阻断（Site）

- 副本可用放行、副本停用拒绝、副本无记录拒绝、Hub 不可达且副本超过 1 小时拒绝、1 小时内放行、开关关闭时全放行
- 事件乱序不覆盖、同事件重复不产生第二行、消费异常进死信队列

### 前端

- 三个路由与权限点落位、菜单按权限显隐、无权限落无权限页
- 列表筛选排序与键集分页、详情抽屉三段、新建与编辑表单四项校验、停用启用弹窗四条影响、受理条轮询节奏
- 账号页端单选与归属货主选择器、未选时提交置灰、列表与详情显示「名称（编号）」

| 安卓端 | 工程未建立，本变更不涉及 |
