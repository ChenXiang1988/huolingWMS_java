| 位置 | 改动 | 约束 |

| 上下文构造 | 新增窄范围判定：契约章无接口条目、契约章含「本次无接口变更」、后端章含「本次无表结构变更」，三条同时成立才为真 | 判定结果写进上下文对象，不改变其他字段 |

- 判定只看文档文本与是否存在接口条目，不读命令行参数、环境变量或外部配置。

## API 接口契约

**本次无接口变更**：不新增、不修改、不删除任何接口，不改字段、错误码与鉴权口径。原因是本次改动对象是构建期校验工具，不在请求链路上。

### 通用约定（沿用既有，不因本次改动调整）

| 项 | 内容 |
|---|---|
| 基础路径与端分组 | 运营端 `/hub/api/**`，主数据协同 `/api/hub/**`、`/api/site/**`，货主端 `/api/owner/**` |
| 认证方式 | 登录后携带访问令牌，失效按既有 401 处理 |
| 错误响应结构 | 错误体含 `code`、`message`、`traceId`、`retryable`；限流与处理中含 `retryAfterMs` |
| 时间与金额口径 | 时间用 UTC 时间戳；数量用字符串承载定点数；本次不涉及金额 |
| 枚举约定 | 状态取值只查 `21-术语与枚举登记表` |
| 分页约定 | 列表沿用键集分页，参数 `cursor` 与 `limit`，默认二十、上限一百 |

### 鲁棒性约定

本次不改请求链路，鲁棒性口径不变：输入校验在入口完成，写接口按幂等约定去重，依赖调用预算小于接口总预算，剩余预算不足时快速失败。脚本侧对应要求是「判定失败不回退为豁免」：任何一条声明读不到，就按未豁免处理。

### 幂等约定

本次无写接口，不产生新的幂等要求。既有写接口的幂等键、作用域、窗口与并发承诺不变。

### 错误码表

本次不新增错误码。下表为脚本执行时会遇到的既有码，不属于接口契约变更。

| 错误码 | HTTP | 重试 | 触发条件 | 调用方处置 | 出现位置 |
|---|---|---|---|---|---|
| `PARAM_INVALID` | 400 | 否 | 校验入参非法 | 修正参数后重跑 | 同步响应 |
| `RATE_LIMITED` | 429 | 是 | 请求超过限流阈值 | 按重试间隔退避后再试 | 同步响应，带重试间隔 |
