## 前端设计

本次不新增路由、不改权限点判定、不新增页面，只改运营端外壳与既有页面的外层层次。路由、列与筛选项保持原样。

| 运营端 | `/home` | 工作台 | 列表页变体 | 重构为页头 + 三张信息卡 |
| 运营端 | `/accounts` | 账号管理 | 列表页 | 外层加页头与容器，列与交互不动 |
| 运营端 | `/roles` | 角色管理 | 列表页 | 同上 |

### 外壳结构

外壳为 `AppShell`，三端共用。本次按 `UI-P04` 的尺寸不改，只补内部构成。

**顶栏（高 56）**：左侧为品牌区——32×32 方块标记（内放端名首字）、平台名「货灵」、副标题「WMS 仓储管理平台」；右侧为工具图标与用户区。顶栏**不放面包屑**，层级由模块页签承担；**不放折叠按钮**，折叠归侧栏底部。工具图标只放有真实动作的项，本次只放一个「帮助」图标，点击打开使用说明抽屉，内容为导航说明与状态标签释义（枚举取自字典包，逐个列出）；没有动作的图标位不摆，不拿空图标凑数。用户区为「首字母方块 + 账号名 + 展开箭头」，下拉含只读角色行与退出登录。

**侧栏（展开 200、收起 64）**：**不放品牌区**，自上而下为模块列表与底部工具条。一级为模块：图标 16、名称 14、右侧展开箭头，展开后显示其下页面；二级为页面：缩进 16、无图标、高 36，当前页用 `UI-T21` 选中底、不加左侧色条。同一时刻只展开当前页所在模块。收起态只显示模块图标，二级不渲染，当前页所在模块的图标用 `UI-T21` 选中底标出，否则看不出所在模块；点击模块图标进入该模块首个有权限的页面，悬浮 300ms 显示模块名。底部工具条固定两项：帮助与折叠按钮，收起态只留图标。视口窄于 1400 时初始按收起渲染：收起 64 加内容区下限 1200 合计 1264，可在 1366×768 下不出横向滚动条；用户手动展开后允许横向滚动。

**模块页签**：内容区顶部，横排当前模块下的页面，当前项下划线，顺序与侧栏二级一致。模块只有一个页面时不渲染页签（工作台即如此）。切换页签不重置页面内筛选、排序与页码；跨模块跳转走侧栏。

**内容区**：宽 1200 至 1440 居中，内边距 24。内容区自上而下为模块页签、页头、页面内容；页签与页头由页面与外壳协作渲染，外壳只管页签。

### 模块与路由元数据

模块是路由 `meta.group` 的取值，页面是路由本身。模块图标不写在每条路由上，集中在 `router/navigation.ts` 的固定表里，避免同一模块七个页面各写一遍。

| 模块 | 顺序 | 图标（`@element-plus/icons-vue`） | 页面 |
|---|---|---|---|
| 概览 | 1 | `Odometer` | 工作台 |
| 主数据 | 2 | `Box` | 商品档案、档案审核、变更申请审核 |
| 权限与审计 | 3 | `User` | 账号管理、角色管理、审计日志 |

路由元数据只保留一个可选字段 `group`；上次改造引入的 `icon` 与 `breadcrumb` 一并移除，不留无人使用的字段。未声明 `group` 的路由进「其他」模块；模块下全部页面无读取权限时，该模块不渲染。

### 组件改动

| 组件 | 位置 | 改动 | 向后兼容 |
|---|---|---|---|
| `AppShell` | `packages/design/src/AppShell.vue` | 顶栏改品牌区、侧栏改两级模块树与底部工具条、去掉面包屑、去掉顶栏折叠按钮 | `nav` 未传时沿用旧 `menus` 平铺渲染，货主端与单仓端不受影响 |
| `ModuleTabs` | `packages/design/src/ModuleTabs.vue` | 新增：模块内页面页签，属性 `tabs` 与 `active`，单页不渲染 | 新组件，无兼容问题 |
| `PageHeader` | `packages/design/src/PageHeader.vue` | 保持：标题、描述、右侧操作插槽 | 已落地 |

`AppShell` 属性清单：`brand`（平台名与副标题）、`nav`（模块树，每项含 `title`、`icon`、`children`）、`collapsible`、`user`；插槽 `actions`、`user`；事件 `navigate(path)`。`menus` 保留为兼容入参，与 `nav` 互斥，优先用 `nav`。`breadcrumbs` 删除。

跳转由调用方接管：设计包不依赖路由，侧栏二级、收起态模块图标与模块页签都只抛 `navigate`，由页面侧用路由库跳转。点击当前页不抛事件，避免冲掉地址栏里的筛选与页码。

### 登录页

左栏宽 480、右栏自适应：左栏为品牌区，包含端名、「多货主同仓作业，一屏看清库存与单据」一句定位与三条能力说明（库存可见、单据可查、权限可管），底色用 `UI-T20` 的页面级底，不加渐变与插图；右栏为表单卡，宽 400，标题「登录」，下方为账号、密码与登录按钮，卡片内边距 32。

窄于 1280 时左栏 `display: none`，表单卡居中。登录失败时错误提示在表单卡内、按钮上方，账号保留、密码清空、焦点回到密码框。

### 工作台

页头为「工作台」加当前日期；下方三张卡横向排列，窄于 1280 时折为单列，卡间距 16。

| 卡 | 内容 | 数据来源 |
|---|---|---|
| 当前账号 | 账号名、角色列表、会话到期时间 | 登录态内存数据 |
| 数据域 | 货主范围与仓范围：全量显示「全部货主」「全部仓」，非全量显示数量（如「3 个货主」「2 个仓」）；登录态只带标识，不显示名称，也不为取名称新增请求 | 登录态内存数据 |
| 功能入口 | 按当前权限生成可进入的页面入口，每项为图标加标题 | 路由表与权限集 |

三张卡的数据全部取自登录态，不额外请求接口；无数据时卡片显示说明文字，不显示空占位，也不编造待办数、库存量等业务指标。

### 状态与查询参数归属

- 折叠状态：存 `localStorage`，键 `wms.admin.sidebar.collapsed`，同浏览器内保留；不进 URL。无存储值时按视口决定初始值，窄于 1400 收起、否则展开。
- 当前模块与展开模块：由当前路由的 `group` 推导，不单独存状态；同一时刻只展开当前页所在模块。
- 列表筛选、排序、页码：仍按 `UI-X04` 写入 URL，本次不动；切换模块页签不重置。

### 页面状态覆盖

五种页面状态逐项落到具体位置，不留未定义的空白：

| 状态 | 登录页 | 工作台 | 列表页 |
|---|---|---|---|
| 加载 | 提交中按钮进入加载态并禁用，文案变「登录中」 | 不发请求，无加载态 | 沿用各页现有加载态，容器高度固定不跳动 |
| 空 | 不适用 | 某卡无数据时卡片内给一句说明 | 容器内显示空态说明，页头与筛选区保持可见 |
| 无权限 | 不适用 | 功能入口卡只列有权限的页面；一个都没有时给说明 | 无读取权限时路由守卫直接跳无权访问页（`UI-X06`），不进页面再拦截；侧栏二级与模块页签同样不渲染该项，模块下全部无权限时模块也不渲染 |
| 失败 | 卡内按钮上方给错误提示，账号保留、密码清空、焦点回密码框 | 不适用 | 保留筛选条件并给重试入口，不整页白屏 |
| 降级 | 不适用 | 不适用 | 不新增降级路径；既有页面的降级表现不变 |

### 适用性说明

本次为纯呈现层改造，下列既有设计要求在本次范围内不成立，逐条写清避免实现时误加：

- 本次没有新增或修改任何写入交互，因此不涉及受理号展示与处理中轮询（D20）；既有写操作的受理流程不变。
- 本次没有新增降级数据展示，因此不涉及数据时间戳提示（D19）；既有降级页面的时间戳展示不变。
- 本次不新增权限点，只读取既有权限集生成菜单与入口，因此没有待并入权限矩阵的条目。

## 后端设计

本次为纯呈现层改造，不改后端。**本次无表结构变更**：不建表、不改字段、不加索引、不写迁移脚本。理由与边界如下。

| 项 | 结论 |
|---|---|
| 数据模型与迁移 | 不新增表、不改字段、不加索引，无迁移脚本 |
| 领域规则与状态机 | 不涉及；页面展示的状态仍由服务端返回，前端不推导 |
| 鉴权 | 不改鉴权链路；菜单裁剪仍用既有登录态返回的权限集，数据域展示只读 |
| 事务与并发 | 不涉及；本次没有新的写路径 |
| 幂等与异步 | 不涉及；工作台不发请求，列表页请求沿用既有接口 |
| 配置与部署 | 不改端口、不改消息队列与数据库配置 |

唯一与后端相关的约束：工作台只读登录态已有的账号、角色、数据域三项，若将来需要更多指标，必须另行新增接口，不得由前端拼接多个既有接口后自行计算。

### 适用性说明

本次不建表、不改表、不写 Flyway 迁移脚本。下列约束属于既有实现，列在此处是为了让实现者确认不误改，不代表本次新增：

| 约束 | 现状 | 本次处置 |
|---|---|---|
| 库位绑定 | 既有迁移已将库存表的 `location_id` 设为非空，库存绑定真实物理库位（INV-01） | 不改 |
| 库存唯一键 | `owner_id`、`location_id`、`container_id`、`sku_id`、`batch_no`、`stock_status`、`serial_no` 七字段构成唯一索引（`04` 与 `11` 已定，D29 的六字段为本表子集） | 不改 |
| `serial_no` 空值策略 | 定为非空且默认空串，不用部分唯一索引；理由见 `04`：联合唯一索引里 NULL 互不相等，留空会产生重复库存行 | 不改，沿用既有结论 |
| 数量约束 | `qty_allocated <= qty_on_hand` 由 CHECK 约束保证（INV-08） | 不改 |

本次也没有表清单与迁移脚本可列：既有迁移编号到 `V20261135` 为止，本次不追加新编号。

## API 接口契约

### 本次接口范围

**本次无接口变更**：不新增、不修改、不删除任何接口，字段、错误码、鉴权与分页口径全部沿用既有契约。登录、刷新、登出、当前账号、账号与角色管理、审计日志、商品档案与变更申请等接口均无变化。

因此本章不定义新的接口编号；前端设计章也不再列举接口编号映射，页面与接口的对应关系维持现状。若后续需要为工作台增加业务指标，必须先在契约中定义接口，再改前端。

### 通用约定（沿用既有，不因本次改动调整）

| 项 | 内容 |
|---|---|
| 基础路径与端分组 | 运营端 `/hub/api/**`，主数据与单仓协同 `/api/hub/**`、`/api/site/**`，货主端 `/api/owner/**`；本次不新增路径 |
| 认证方式 | 登录后携带访问令牌，令牌失效按既有 401 处理并跳登录页，登录后回原路径 |
| 错误响应结构 | 错误体含 `code`、`message`、`traceId`、`retryable`；限流与处理中含 `retryAfterMs`，可带 `dataTimestamp`、`details` |
| 时间与金额口径 | 时间用 UTC 时间戳；数量用字符串承载定点数；本次不涉及金额 |
| 枚举约定 | 状态取值只查 `21-术语与枚举登记表`，前端不新增枚举、不自行映射中文 |

### 鲁棒性约定

沿用既有约定，不因本次改造放宽：登录态失效时按既有鉴权响应跳登录页并回到原路径；列表请求失败时保留筛选条件并给重试入口；不把空结果当作成功展示；外壳渲染不依赖任何网络请求，断网时外壳与菜单仍可用，只有页面数据区受影响。

### 幂等约定

本次无写接口，不产生新的幂等要求。既有写接口的幂等键、作用域、窗口与并发承诺不变；前端改造不得改变既有写操作的提交次数，重试仍走原逻辑。

### 错误码表

本次不新增错误码。下表为本次改造会触及的既有错误码，取值与处置以既有实现为准，前端只做展示与跳转，不自行解释。

| 错误码 | HTTP | 重试 | 触发条件 | 调用方处置 | 出现位置 |
|---|---|---|---|---|---|
| `PARAM_INVALID` | 400 | 否 | 列表筛选参数非法 | 提示并按字段修正 | 同步响应 |
| `FORBIDDEN_OWNER` | 403 | 否 | 访问非本数据域货主数据 | 提示无权限，不重试 | 同步响应 |
| `FORBIDDEN_SITE` | 403 | 否 | 访问非本仓数据 | 提示无权限，不重试 | 同步响应 |
| `RATE_LIMITED` | 429 | 是 | 请求超过限流阈值 | 按重试间隔退避后再试 | 同步响应，带重试间隔 |

### 契约验收

| 检查项 | 验收方式 |
|---|---|
| 本次无契约变更 | 比对 `code/contracts/openapi.json`，本次分支不得产生字段与路径差异 |
| 既有接口仍可用 | 现有集成测试全部通过，接口路径与响应字段不变 |
| 前端不解释错误码 | 代码检索确认页面只做提示与跳转，无按错误码分支的业务判断 |
| 权限裁剪不变 | 无权限菜单不渲染的判定仍由登录态权限集决定，未改为前端硬编码 |
