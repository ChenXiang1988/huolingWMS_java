# Proposal

## Why

运营端界面骨架单薄，与 `12a` 要求的「顶栏 + 多级侧边菜单」不相称：顶栏只有端名文字与退出按钮，侧栏直接使用 Element Plus 默认菜单且只有一级，工作台是一张五行描述列表，登录页是一张 360 宽白卡居中。页与页之间没有统一的层次节奏，功能增加后只会越堆越乱。

第一轮补齐了顶栏、侧栏分组、登录页与工作台，但导航仍是一级平铺、面包屑承担层级。对照同仓 apeadmin 与「西之月」原型的框架，差距在导航结构本身：品牌应在顶栏、侧栏应为两级模块树、模块内切换应有页签。本次按此调整，令牌取值不动。

## What Changes

- **顶栏**：改为左侧品牌区（方块标记 + 平台名 + 副标题），右侧帮助图标与用户下拉；去掉面包屑与折叠按钮。工具图标只放有真实动作的项，本次只有「帮助」一个。
- **侧栏**：去掉品牌区，改为两级模块树——一级模块带图标、名称与展开箭头，二级为页面；同一时刻只展开当前页所在模块；底部固定帮助与折叠按钮。收起态只显示模块图标。
- **模块页签**：内容区顶部横排当前模块下的页面，当前项下划线；模块只有一个页面时不渲染。
- **路由元数据**：只保留 `group` 一个可选字段；上一轮引入的 `icon` 与 `breadcrumb` 移除，模块图标集中在导航配置里。
- **登录页**：左右分栏，左侧品牌区，右侧表单卡；视口窄于 1280 时只留表单卡。
- **工作台**：页头加三张信息卡（当前账号、数据域、功能入口），只展示登录态已有数据。
- **列表页外层**：统一页头与容器，改造账号、角色、审计、商品档案、档案审核、变更申请审核六页的外层层次，不动列、筛选项与交互。
- **明确不改**：主色 `UI-T01`、圆角 `UI-T15`、阴影 `UI-T16`、动效 `UI-T18`、图标集 `UI-T19`；不引入暗色模式、渐变、国际化；不做全局搜索（没有跨模块检索接口，做了是摆设）。
- **范围**：只到运营端。货主端、单仓端、移动作业端本次不动；`AppShell` 为三端共用，改造 MUST 保持向后兼容，未传新属性时行为与现状一致。

## Capabilities

### New Capabilities

- `admin-shell-visual`: 运营端外壳与页面骨架的构成规则，覆盖顶栏品牌区、侧栏两级模块树、模块页签、工作台、登录页与列表页页头。

### Modified Capabilities

无。`12a-网页页面与分端规格.md` 本次新增 `UI-P12`~`UI-P16` 五条，作为本能力的权威源，不属于能力变更。

## Impact

- 前端：`code/web/packages/design` 改造 `AppShell`、新增 `PageHeader` 与 `ModuleTabs`；`code/web/apps/admin` 改造布局、路由元数据与导航配置、登录页、工作台与六个列表页；两个包的 `package.json` 增加 `@element-plus/icons-vue`。
- 设计文档：`v2/12a` 新增五条并修订顶栏与侧栏口径，`v2/log.md` 记一条改动。
- 后端、接口契约、数据库迁移：无改动。
- 既有实现：`apps/owner`、`apps/site` 复用同一 `AppShell`，本次不改其页面；外壳新增能力全部可选，不传即维持现状。
