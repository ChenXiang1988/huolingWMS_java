# Spec Delta

## Purpose

定义运营端外壳与页面骨架的构成规则，使导航、登录入口、工作台与列表页在不动视觉令牌的前提下具备统一层次，且改造对共用同一外壳的货主端与单仓端保持向后兼容。

## ADDED Requirements

### Requirement: 顶栏构成

系统 SHALL 将运营端顶栏分为左右两组：左侧为品牌区（方块标记、平台名、副标题），右侧为工具图标与用户区。顶栏 MUST NOT 放面包屑与折叠按钮，层级由模块页签承担、折叠归侧栏底部。工具图标 MUST 只放有真实动作的项，不得用空图标占位；用户区 MUST 展示当前账号并收起为下拉，退出登录入口放在下拉内。

#### Scenario: 进入二级页面
- **WHEN** 用户从工作台进入账号管理页
- **THEN** 顶栏左侧仍显示平台名与副标题，当前所在模块与页面由模块页签标出，顶栏不出现路径文字

#### Scenario: 打开帮助
- **WHEN** 用户点击顶栏的帮助图标
- **THEN** 打开使用说明抽屉，内容为已实现的快捷键与字段说明，不出现「即将上线」一类占位

### Requirement: 侧栏两级模块菜单

系统 SHALL 由路由元数据中的模块字段生成两级侧栏：一级为模块（图标加名称加展开箭头），二级为该模块下的页面。同一时刻 MUST 只展开当前页所在模块；折叠态 MUST 只显示模块图标、隐藏二级，并在悬浮时显示模块名；折叠状态 SHALL 在同一浏览器内保留。

#### Scenario: 折叠侧栏
- **WHEN** 用户点击侧栏底部的折叠按钮
- **THEN** 侧栏宽度从 200 收为 64，二级页面与模块名隐藏，模块图标居中，鼠标悬浮显示模块名

#### Scenario: 收起态点击模块
- **WHEN** 侧栏收起时用户点击某模块图标
- **THEN** 进入该模块下第一个有权限的页面，侧栏保持收起

#### Scenario: 页面未声明模块
- **WHEN** 某路由未声明 `group`
- **THEN** 该项归入「其他」模块并正常渲染，不出现空模块

### Requirement: 模块页签

系统 SHALL 在内容区顶部渲染当前模块下的页面页签，顺序与侧栏二级一致，当前项下划线。模块只有一个页面时 MUST NOT 渲染页签。切换页签 MUST NOT 重置页面内筛选、排序与页码。

#### Scenario: 单页模块不显示页签
- **WHEN** 用户在工作台
- **THEN** 内容区顶部不出现页签行，工作台页头直接位于内容区顶部

#### Scenario: 模块内切换
- **WHEN** 用户在商品档案页点击「档案审核」页签
- **THEN** 进入档案审核页，侧栏二级高亮同步切换，两页各自保留自己的筛选条件

### Requirement: 登录页骨架

系统 SHALL 将运营端登录页设为左右分栏：左侧品牌区展示端名、一句话定位与三条能力说明，右侧表单卡承载账号与密码。视口窄于 1280 时 MUST 隐藏品牌区，只保留表单卡且居中。

#### Scenario: 登录失败
- **WHEN** 账号或密码错误导致登录失败
- **THEN** 错误提示定位在表单卡内，账号输入保留，密码输入清空，焦点回到密码框

### Requirement: 工作台骨架

系统 SHALL 将运营端工作台设为页头加信息卡：页头给标题与当前日期，信息卡不超过三张，分别展示当前账号与角色、数据域范围、当前权限可见的功能入口。工作台 MUST 只展示登录态已有的数据，不得虚构业务指标、待办数量或趋势。

#### Scenario: 无可见功能入口
- **WHEN** 当前账号除工作台外没有任何功能权限点
- **THEN** 功能入口卡显示说明文字，不显示空白卡片，也不伪造入口

### Requirement: 列表页层次

系统 SHALL 让运营端列表页统一为「页头（标题、描述、主操作）→ 筛选区 → 表格 → 分页」，筛选区与表格 MUST 处于同一容器内，分页位于容器右下。本次改造 MUST NOT 改变既有列表的列、筛选项、排序与权限判断。

#### Scenario: 列表页无数据
- **WHEN** 查询结果为空
- **THEN** 容器内显示空态说明，页头与筛选区保持可见，不整页白屏

### Requirement: 令牌与兼容约束

本次改造 MUST NOT 修改主色、圆角、阴影、动效与图标集相关令牌（`UI-T01`、`UI-T15`、`UI-T16`、`UI-T18`、`UI-T19`），MUST NOT 引入暗色模式、渐变背景或国际化。`AppShell` 为三端共用组件，新增属性 MUST 全部可选，未传时行为与改造前一致。

#### Scenario: 货主端未升级
- **WHEN** 货主端应用继续以改造前的 `menus` 入参调用外壳组件
- **THEN** 顶栏、侧栏与内容区的布局尺寸不变，侧栏仍按旧平铺菜单渲染，不出现模块页签与用户下拉，也不报错
